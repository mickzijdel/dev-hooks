Let's get you coding with Claude

You're setting up your computer to write code with an AI helper. Keep this page next to the black text window (called the terminal — a window where you type instructions instead of clicking) and tick off each step as you go. The whole thing takes about 15 minutes.

Using Windows? Start here first

Most coding tools expect a small Linux workspace that runs inside Windows, called WSL2. You only set it up once.

  1. Open PowerShell as Administrator (right-click it → "Run as administrator") and run this:
wsl --install
  1. Restart your computer when it asks.
  2. Open Ubuntu from the Start menu — a terminal window opens.
  3. Paste the main command below into that Ubuntu window and carry on.
  1. The terminal is the window where you type instructions to your computer. This one command starts everything off — copy it, paste it in, and press Enter.
    curl -fsSL https://raw.githubusercontent.com/mickzijdel/dev-hooks/main/install.sh | bash
  2. Claude Code is an AI helper that lives in your terminal and can set things up for you. The command above installs it automatically — just wait for it to finish.
  3. A browser window opens asking you to sign in — just like signing into any app. You can make a free account here if you don't have one. Your code always stays on your own computer.
  4. Claude learns new skills through add-ons (like installing an app on a phone). The command adds the one that knows how to set up the rest of your machine.
  5. When the command finishes, type claude and press Enter. When Claude answers, type set me up. From here Claude takes over and walks you through the rest — your coding toolbox, GitHub (where coders keep and back up their work), your editor — explaining each piece as it goes.
