# Wait What

Your last answer did not land. Re-pitch it:

- Start with a little context: where the work is now, and which question the answer is for.
- Write in ASD-STE100 Simplified Technical English.
- Aim for about a 10th-grade reading level.
- Make it shorter than the first version.
